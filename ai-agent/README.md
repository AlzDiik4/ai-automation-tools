# AI Agent Automation Pipeline

Lightweight modular Python pipeline for LLM agent orchestration, task routing, and structured JSON output processing.

## Features
- **Context Management:** Built-in memory buffer for handling multi-turn agent execution.
- **Configurable Payloads:** Dynamic temperature and token constraints per execution run.
- **Logging & Monitoring:** Clean output stream tracking for pipeline debugging.

## Quickstart
```bash
python main.py
